im.jjzz v7 — TECHNICAL INFO fields added

admin.html now supports:
- Camera
- Lens
- Filter
- Format
- Color
- Aspect Ratio

Example:
Camera       Sony FX3
Lens         Sigma 24–70mm F2.8
Filter       Tiffen Black Pro-Mist 1/4
Format       4K UHD / XAVC S-I
Color        S-Log3 / DaVinci Resolve
Aspect Ratio 2.39:1

Workflow:
1. Replace admin.html, project.html, cinematic.css with these files.
2. Open admin.html.
3. Enter Technical fields for each project.
4. Download/export projects.js from admin.
5. Replace your website's existing projects.js with the exported file.
